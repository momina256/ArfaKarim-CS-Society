# CS Society Python Projects

A collection of small projects and mini-games created by CS Society members.

## How to Submit
Github and git (a version control system) can be overwhelming for new users. While you can send your code to the said number, a PR (Pull Request) is the official way to "upload" your code here. 
Here are detailed instructions for how to contribute (adapted from https://github.com/firstcontributions/first-contributions):
1. Fork this repo by clicking over the fork button (the option is visible when you scroll to the top)
2. When making a fork, you can leave the defaults as they are and click "Create fork"
3. When forked, your fork should be automatically loaded. If not, click on the hamburger menu and select your fork (should be <your username>/ArfaKarim-CS-Society) **Note:** It is necessary to create a Github account for these steps
4. Visit [this url](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account) in a **new tab** and follow the process for your relevant operating system
5. Now head over to "Git bash" on Windows, Terminal on Linux/Mac OS and copy the "Clone with SSH" URL that is presented on your fork when you click on the green "<> Code" button
6. Now write in the terminal "git clone " (don't forget the space) and paste the URL and hit enter.
7. Do a `cd ArfaKarim-CS-Society`
8. Create a new branch with your project name, e.g `git checkout -b mycoolproject`
9. Now just simply copy out your file(s)/project(s) you created to this folder. If you followed these instructions in a new terminal (not on a previous one you used for following the SSH tutorial), the ArfaKarim-CS-Society directory should be in $HOME folder (or /Users/<user>/ in Windows maybe).
9. Do a `git push -uf <your branch name> origin` and the code should be pushed alright
10. Come back to your fork on your browser and click on the green button "Compare and pull". Your code would be send now to be reviewed. Add a descriptive message as you wish.
11. If there are any problems, feel free to open up an issue! You can head over to this repository page (not your fork) and click on the issues tab and create one detailing what can be improved in this guide or the repo overall or if there is any problem you faced. We welcome your suggestions!

## What to Submit
- Mini-games (guessing game, quiz, hangman, etc.)
- Small utilities (calculator, random generator)
- Fun scripts or creative projects

Name your file like:
yourname_projectname.py
